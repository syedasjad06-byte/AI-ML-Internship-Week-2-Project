# Week 2 — Deep Learning Project
## Skill Set Go EduTech AI/ML Internship

This project pack covers the four Week 2 deliverables:
1. Neural Network in PyTorch
2. CNN Image Classifier
3. Hyperparameter Experimentation
4. Deep Learning Technical Report

### How to use
- Open each `.ipynb` file in Google Colab.
- Run the cells from top to bottom.
- Save the executed notebooks with outputs.
- Upload the project folder to GitHub for submission.

### Notes
- Task 2.1 and 2.3 use a small synthetic Student Performance dataset generated inside the notebook, so the notebooks are self-contained.
- Task 2.2 uses CIFAR-10 through `torchvision` and downloads the dataset when the notebook is run.
